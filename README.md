# FaithDate

FaithDate is a faith-based dating app prototype built from the provided design exports.
It is implemented as an Expo React Native app for iOS, Android, and web preview.

## Development

Install dependencies:

```sh
npm install
```

Start Expo:

```sh
npm run dev
```

Run on a platform:

```sh
npm run ios
npm run android
npm run web
```

Run checks:

```sh
npm run lint
npm run typecheck
npm run test
npm run build
```
